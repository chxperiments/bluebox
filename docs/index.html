SDK

      
Sandboxes as a function call. From Python or Go.


      

        

          

            

              
              
              
            

            
            
          


from bluebox import Sandbox

# a persistent microVM: up on enter, down on exit
with Sandbox("agent") as sb:
    sb.write_file("/data/task.py", code)
    r = sb.exec(["python3", "/data/task.py"])
    print(r.stdout_text, r.exit_code, r.duration_ms)

# a fresh microVM per call, from the warm pool
r = Sandbox("agent").run("pytest -q")
r.check()   # raises on a non-zero exit


sb := bluebox.New().Sandbox("agent")
if err := sb.Up(ctx); err != nil {
	return err
}
defer sb.Down(ctx)

r, err := sb.Exec(ctx, bluebox.Cmd("python3", "task.py"))
fmt.Println(string(r.Stdout), r.ExitCode, r.Duration)

// a fresh microVM per call, from the warm pool
r, err = sb.Run(ctx, bluebox.Sh("pytest -q"))


bluebox new agent --from tiny-python
bluebox build agent               # verifies its own kernel

bluebox up agent                  # boot once
bluebox exec agent -- python3 task.py
echo 'print(6*7)' | bluebox exec agent -- python3 -
bluebox down agent

bluebox run agent -- pytest -q    # fresh VM, then gone

About

      

        

          

            bluebox gives you a sandbox with its own kernel. Not a container
            sharing yours — a real microVM, ready in tens of milliseconds from a
            warm pool, built from one file you can read.
          

          

            Install anything into it. Break it, fill it with junk, delete half
            the filesystem. The next command gets a clean machine, and the work
            you meant to keep is still in /data.
          

          

            Built on podman and libkrun. The build compares the sandbox kernel
            against the one a plain container sees, and refuses to hand you a
            sandbox that only looks isolated.
          

        

        

          
isolationits own kernel, via KVM

          
confinedVMM: no new privs, 6 caps, own UID

          
start~44ms warm, ~1.4s cold

          
exec~15ms in a running VM

          
persists/data, and nothing else

          
configone YAML Bluefile

          
sdkpython, go

          
platformlinux, macos
